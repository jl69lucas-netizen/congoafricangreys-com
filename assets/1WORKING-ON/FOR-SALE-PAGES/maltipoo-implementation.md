## 🎨 CONTENT FORMATTING GUIDELINES

### Readability Standards:

**Paragraph Length:**
- Opening paragraphs: 2-3 sentences maximum
- Body paragraphs: 3-5 sentences
- Never exceed 5 sentences without a break
- Use short paragraphs for mobile readability

**Header Hierarchy:**
- H1: Only one per page (primary keyword-rich)
- H2: Major sections (15-20 total)
- H3: Subsections within H2 sections
- H4/H5: Specific details within subsections
- Every header must be conversational and include keywords naturally

**Bolding Strategy:**
- Bold key benefits and features
- Bold statistics and numbers (2-year guarantee, 90% trained, etc.)
- Bold important terms on first mention
- Don't over-bold (max 10-15% of text)

**List Usage:**
- Use checkmark bullets (✓) for benefits and features
- Use numbered lists for processes and steps
- Use standard bullets for neutral information
- Keep list items parallel in structure

**Visual Elements:**
- Images every 300-400 words
- Videos in Sections 4, 7, 13
- Tables for comparing sizes (Section 3)
- Infographics for health protocol (Section 12)
- Interactive map (Section 19)
- Animated counters (Section 23)

## ⚠️ COMMON MISTAKES TO AVOID

1. **Keyword Stuffing:** Never force keywords unnaturally. The document provides natural integration examples—follow them.

2. **Ignoring Mobile:** 65%+ of pet searches happen on mobile. Test every section on smartphones.

3. **Slow Load Times:** Compress images, use lazy loading, minimize scripts. Target <3 second load time.

4. **Generic Content:** Every section must provide specific, valuable information. No fluff or filler.

5. **Broken Links:** Test all internal and external links monthly. Fix immediately if broken.

6. **Missing Alt Text:** Every image needs descriptive, location-specific alt text for SEO and accessibility.

7. **Inconsistent NAP:** Ensure Name, Address, Phone identical across website, Google Business, citations.

8. **Neglecting Updates:** Refresh available puppies, testimonials, and content monthly minimum.

9. **Poor CTA Placement:** Too many CTAs = confusion. Follow provided placement strategy.

10. **Forgetting Schema:** Schema markup is critical for rich results. Implement all provided examples.
