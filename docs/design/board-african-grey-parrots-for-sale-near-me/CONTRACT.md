# Page Board canvas — /african-grey-parrots-for-sale-near-me/

Artboards are generated by scripts/board_canvas.py from data/pages/african-grey-parrots-for-sale-near-me/board.json.
Every word is that section's own record; siblings only subtracted candidates. Edit layout here; a text edit is written back
into the record by board_approve.py at approval. File naming: <section>--<candidate>--<Mobile|Desktop>.dc.html, with a
candidate's `#` spelled `+` (a `#` breaks the file:// URL the editor and the thumb cutter load); the board maps it back.
The folder is rewritten on every run: a candidate the ledger withdrew is deleted, never left behind.
